## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.

## BFC Smart Work local demo

This project currently uses Laravel sessions and a JSON repository for demo accounts, access requests, roles, scopes, notifications, audit records, and work tasks. It does not require MySQL and does not use migrations for this demo flow.

1. Create the first system administrator from the project directory:

   ```powershell
   php artisan bfc:setup-system-admin
   ```

   Enter the administrator email, name, and password when prompted. The password prompt is hidden; the password is hashed and is not stored in source code. The command is one-time: it refuses to create another `SYSTEM_ADMIN`.
2. Open the app and sign in through the same login page used by employees.
3. In **Cài đặt → Quản lý tài khoản & phân quyền**, configure the company email domains before accepting employee registrations. Domains are intentionally empty by default; registering an address does not verify ownership of that email.
4. Approve or reject pending access requests, assign a non-admin role and explicit data scope, and review the audit history.

The default private JSON store is `storage/app/private/demo-auth/`. Set `BFC_DEMO_AUTH_PATH` to use another private local path. Keep this application on a trusted local machine: email verification, account recovery, production deployment hardening, and cross-device synchronization are not included. Previously browser-stored tasks are not deleted; a signed-in user with task-creation permission can import a copy from **Cài đặt**.
